# Repository Template

This repository is the standard template for new projects in the organization.

## Purpose

Use this template to ensure every new repository starts with the same baseline documentation, contribution guidelines, ownership rules, security guidance, and issue/PR templates.

## Standard Files

This template includes:

- README.md
- .gitignore
- CONTRIBUTING.md
- SECURITY.md
- CODEOWNERS
- Pull request template
- Issue templates
- License or proprietary notice

## How to Use

1. Create a new repository from this template.
2. Update the README with the project-specific purpose.
3. Configure project-specific owners and permissions.
4. Review branch protection and repository settings.
5. Begin development.
